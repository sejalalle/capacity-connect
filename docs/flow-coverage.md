Audit basis: `2026-09-26`. Sources: `server/src/{models,routes,services,seed}`, `client/src/{pages,components,routes,utils}`, `server/test/*.test.js`.

Status values:

| Status | Meaning |
| --- | --- |
| **Implemented** | A mounted surface exists, is reachable by the intended role, and (unless noted) is exercised by an executed test. |
| **Partial** | Core path exists but a stated sub-element is absent, or the only evidence is a route/file that no test exercises. |
| **Missing** | No mounted surface, or the expected behaviour cannot be produced at all. |

Evidence rule: a file or route is **not** evidence by itself. Where a row says "test ✓", an executed `server/test/*.test.js` case asserts it.
